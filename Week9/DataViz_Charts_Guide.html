01

Column Chart

Compare values side-by-side across distinct categories using vertical bars.

Example · Q1 Product Sales (₹)
📋

How to Create in Excel

1
Select your data range — e.g. A1:B5
2
Go to Insert → Column or Bar Chart → Clustered Column
3
Click the + icon → tick Data Labels and Axis Titles
4
Click the chart title → rename it to "Q1 Sales by Product"
5
Right-click any bar → Format Data Series → change fill color
6
Resize and reposition the chart on your sheet
🏢

Where It's Used

📦

E-commerce companies like Flipkart & Meesho compare product category sales every quarter

🏏

Cricket analytics dashboards compare runs scored by each batsman per match

🏫

College admin offices compare marks per subject across a batch

📱

App developers compare daily active users across different features

✅

When to Use a Column Chart

✓

You want to compare values across different categories at a single point in time

✓

You have 5–12 categories — too few is boring, too many is cluttered

✓

Category names are short enough to fit on the X-axis without overlapping

✓

You want to show a grouped comparison (Clustered) or cumulative total (Stacked)

💡 Pro Tip: Use the Stacked Column variant when you want to show both the individual parts AND the total simultaneously — e.g., revenue broken down by region, stacked to show the overall company total.

02

Line Chart

Track how a value changes continuously over time using connected data points.

Example · Monthly Sales Trend (₹) with Trendline
📋

How to Create in Excel

1
Select your data range — e.g. A1:B7
2
Go to Insert → Line or Area Chart → Line with Markers
3
Add Title: "Monthly Sales Trend" and Axis Titles
4
Right-click line → Format Data Series → tick Smooth Line
5
Right-click line → Add Trendline → Linear → tick Display Equation
6
Use Design tab → Chart Styles to apply a theme instantly
🏢

Where It's Used

📈

Stock market platforms like Zerodha and Groww show SENSEX/NIFTY price movements over time

🌡️

Weather apps track temperature and rainfall trends month by month

🛵

Zomato & Swiggy track daily order volume trends to plan delivery partner availability

🏥

Hospitals track patient admissions over weeks to predict seasonal surges

✅

When to Use a Line Chart

✓

You are working with continuous data across a time axis — hours, days, months, years

✓

You want to show a trend or rate of change — is it growing, falling, or flat?

✓

You need to compare multiple series over the same time period (e.g., Product A vs B)

✓

You want to add a trendline to project future values

💡 Pro Tip: Adding a trendline with Display Equation on chart is your first step into predictive analytics. The slope of the line tells you by how much your value is changing per time period — real data science!

03

Pie Chart

Show how individual parts make up the whole — proportions and percentages at a glance.

Example · Sales Distribution by Product (Total = ₹7,51,000)
📋

How to Create in Excel

1
Select your data range — e.g. A1:B5
2
Go to Insert → Pie or Doughnut Chart → 2-D Pie
3
Add Title: "Sales Distribution by Product"
4
Click + → Data Labels → More Options → tick Percentage
5
Right-click one slice → Format Data Point → set Point Explosion = 15% to highlight it
6
For a modern look, try Doughnut Chart from the same Insert menu
🏢

Where It's Used

🗳️

News channels show election vote share — BJP vs Congress vs Others

💰

Personal finance apps like ET Money show portfolio allocation across assets

🛒

FMCG companies like HUL show market share across soap/shampoo brands

📊

Annual reports show revenue mix — domestic vs export, product A vs B vs C

✅

When to Use a Pie Chart

✓

You want to show part-to-whole relationships — how each category contributes to 100%

✓

You have 6 or fewer categories — more than 6 slices become impossible to read

✓

The proportional difference between categories is significant enough to be visually meaningful

✓

You want to highlight one dominant segment using the Explode Slice feature

⚠️ Common Mistake: Never use a pie chart to show trends over time. If someone says "show me how sales grew this year" — that's a Line Chart, not a pie. Pie is only for "what is the share of each part right now."

04

Bar Chart

The horizontal cousin of the column chart — ideal for rankings and long category names.

Example · GDP by Country (Trillion $) — Ranked
📋

How to Create in Excel

1
Select data range — e.g. A1:B6
2
Go to Insert → Column or Bar Chart → Clustered Bar (horizontal)
3
Add Title: "GDP Comparison by Country"
4
Right-click the Y-axis → Format Axis → tick Categories in Reverse Order
5
Right-click any bar → Format Data Series → set Gap Width = 50% for wider bars
6
Add Data Labels → Outside End so numbers appear to the right of each bar
🏢

Where It's Used

🌍

World Bank & IMF use horizontal bar charts to rank countries by GDP, HDI, literacy rate

🏆

Olympic medal tables and sports rankings showing countries or players in order

🛍️

Retail chains rank top 10 cities by revenue — city names are long and fit better on Y-axis

📋

HR departments rank departments by employee satisfaction scores in surveys

✅

When to Use a Bar Chart

✓

Your category labels are long — country names, product names, department names that don't fit on X-axis

✓

You are showing a ranked list — top 5, top 10 — where order matters

✓

You have many categories (10+) — horizontal layout scales better than vertical

✓

The data is not time-based — you are comparing items, not a progression over time

💡 Pro Tip: Always sort your data in descending order before creating a bar chart. Then use "Categories in Reverse Order" in Excel so the highest value appears at the top. This makes your ranking immediately readable.

05

Area Chart

Like a line chart, but the filled area below the line emphasizes volume and cumulative magnitude.

Example · Company Revenue Growth 2018–2022 (₹)
📋

How to Create in Excel

1
Select your data range — e.g. A1:B6
2
Go to Insert → Line or Area Chart → Area
3
Add Title: "Company Revenue Growth", Axis Titles: X=Year, Y=Revenue
4
Right-click the filled area → Format Data Series → Fill → set Transparency = 40%
5
For multiple products, use Stacked Area to show combined volume over time
🏢

Where It's Used

📉

Trading apps use area charts for portfolio value over time — the filled area shows wealth accumulation

🌐

Google Analytics shows website traffic using area charts — volume of visitors per day

⚡

Power grid monitoring tracks electricity consumption over 24 hours using stacked area charts

🏗️

Startups use area charts in pitch decks to show ARR (Annual Recurring Revenue) growth

✅

When to Use an Area Chart

✓

You want to show volume or magnitude over time, not just direction — the filled area gives a sense of size

✓

You want to show cumulative totals that are building up over time

✓

You have multiple series and want to see how they combine — use Stacked Area

✓

The data has a clear upward trajectory — area charts are most impactful with growth stories

💡 Pro Tip: Set fill transparency to 40–50% when you have overlapping series — otherwise one area hides the other completely. Stacked Area avoids this problem and is better when the total is meaningful.

06

Combination Chart

Two chart types in one — display data series with different scales on a dual-axis chart.

Example · Monthly Sales (₹) vs Profit Margin (%) — Dual Axis
📋

How to Create in Excel

1
Select all data — e.g. A1:C7 (Month, Sales, Profit%)
2
Go to Insert → Combo Chart → Custom Combo Chart
3
For Sales: select Clustered Column
4
For Profit %: select Line and tick Secondary Axis checkbox
5
Click OK — left Y-axis = Sales (₹), right Y-axis = Profit (%)
6
Label both Y-axes clearly in Chart Elements so readers know which scale is which
🏢

Where It's Used

📊

Quarterly earnings reports by companies like TCS and Infosys — Revenue (bars) + Net Margin % (line)

🌤️

Weather forecasting shows temperature (line) and rainfall in mm (bars) on the same chart

🏭

Manufacturing dashboards show units produced (column) vs defect rate % (line) together

🛒

E-commerce — number of orders (bars) alongside average order value (line) per month

✅

When to Use a Combination Chart

✓

You have two data series with very different scales — e.g. ₹1,50,000 in sales but only 8% profit margin

✓

You want to show correlation between two variables — does profit margin rise when sales rise?

✓

You want to show absolute values AND a rate/percentage simultaneously

✓

The relationship between the two series is the insight itself — e.g., sales dipped in March but profit went up

💡 Pro Tip: Always label both Y-axes explicitly. Readers often get confused about which axis belongs to which series. Use matching colors — if Sales bars are blue, make the left axis label blue too.
Dual AxisColumn + LineSecondary Axis Two ScalesCorrelation

Heat Map

Color-coded cells that reveal data intensity — high values glow green, low values flash red.

🗺️

Live Example — Regional Sales Performance (Score /100)

Region Q1Q2Q3Q4Avg
📋

How to Create in Excel

1
Enter your data table in Excel
2
Select only the numeric cells — e.g. B2:E5 (do NOT include row/column headers)
3
Go to Home → Conditional Formatting → Color Scales
4
Choose Green–Yellow–Red: highest value = dark green, lowest = red
5
To customize: Manage Rules → Edit → set exact min/mid/max values and colors
6
Try also: Data Bars (mini bar in each cell) as an alternative from the same menu
🏢

Where It's Used

🧬

Bioinformatics — gene expression heat maps show which genes are active or inactive across samples

🏫

Exam analytics — teachers identify which topics students scored low on across an entire class

🖥️

Website analytics — UX teams use click heat maps to see where users click most on a page

🌏

Sales dashboards in FMCG companies compare store-wise performance across states and quarters

✅

When to Use a Heat Map

✓

You have a matrix of numbers — rows = categories, columns = time periods or attributes

✓

You want to spot outliers and patterns instantly — without reading individual numbers

✓

You are doing performance monitoring — which area/product/person is underperforming?

✓

Your data has clear high/low extremes that color-coding will make visually obvious

💡 Pro Tip: Heat maps are not a standard "chart" in Excel — they are built using Conditional Formatting, which is under the Home tab, not the Insert tab. This is a common source of confusion for beginners.
Conditional FormattingColor Scale Matrix DataPattern DetectionPerformance
08

Sparklines

Tiny cell-sized charts that reveal trends at a glance — perfect for dashboards and reports.

⚡

Live Example — Monthly Sales with Inline Sparklines

Product JanFebMarAprMayJun Trend (Sparkline) MinMax
📋

How to Create in Excel

1
Click the cell where the sparkline should appear — e.g. H2
2
Go to Insert → Sparklines → Line (or Column / Win-Loss)
3
In dialog: Data Range = B2:G2 | Location Range = H2 → Click OK
4
Copy cell H2 down to H3, H4 for each remaining row
5
With sparklines selected: Sparkline tab → tick High Point (green) and Low Point (red)
6
Increase row height to 40px+ so sparklines are clearly visible
🏢

Where It's Used

📋

Financial dashboards — Bloomberg terminals show stock price sparklines next to each ticker symbol

🏥

Hospital patient monitoring — tiny trend lines next to each patient's vitals in a summary table

🧑‍💼

HR reports — employee performance trend over 6 months shown compactly in a single table row

📦

Inventory management — stock level trends for 50+ SKUs shown in one scrollable table

✅

When to Use Sparklines

✓

You have many rows of data and making a full chart for each would be impractical

✓

You want a quick trend indicator alongside the raw data — without leaving the table

✓

You are building a dashboard or executive summary where space is limited

✓

You want to show Win/Loss patterns — e.g., daily profit (positive) vs loss (negative) over a month

💡 Three Types: Line = shows direction/trend. Column = shows comparative bar size per period. Win/Loss = shows only positive vs negative — binary. Choose based on whether magnitude or direction matters more.
